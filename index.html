Secure AWS Web Platform

Defense-in-depth architecture & automated remediation

Repo ↗

Architected a two-AZ VPC with public/private subnet segmentation, tiered Security Groups, NACLs, and VPC Endpoints (S3 gateway + SSM interface endpoints) via Terraform — no NAT Gateway and no SSH keys, with every server reachable only through AWS Systems Manager Session Manager. Built a defense-in-depth web tier (CloudFront + ALB + EC2 + RDS MySQL + EFS) secured by a shared-secret origin header that blocks direct load-balancer access, with audit coverage from CloudTrail, VPC Flow Logs, and CloudWatch alarms/dashboard with SNS alerting. Added automated incident response: an EventBridge-triggered Lambda that revokes any open SSH/RDP Security Group rule within about a minute, plus AWS Backup with a governance-mode Vault Lock for tamper-resistant daily backups.
